# A. Bigrams

## Problem Statement
Given `n` integers representing the number of cards available for each of the first `n` lowercase Latin letters, construct a string using every card exactly once.

A **bigram** is a pair of adjacent characters in a string. The resulting string must contain at least two occurrences of the same bigram.

Determine whether it is possible to construct such a string.

## Examples

**Example 1:**
```text
Input:
1
1

Output:
NO
```

**Example 2:**
```text
Input:
1
3

Output:
YES
```

**Example 3:**
```text
Input:
2
2 1

Output:
YES
```
